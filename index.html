How pressure is defined

Each delivery gets a Pressure Index (0–100) built only from the match state before the ball is bowled, so no future information is used.

  • Chases: chase difficulty D = runs needed ÷ expected remaining runs (given balls & wickets left), required rate vs the competition-season par, closeness 4·WP·(1−WP) from a win-probability model (AUC 0.90), wickets lost, stage, recent collapse, dot-ball squeeze.
  • First innings: projected-total shortfall vs par, wickets above the expected count for the stage, wickets lost, stage (final five overs boosted), recent collapse, squeeze.
  • Scaled to a percentile within competition × innings. Low <50 · Medium 50–75 · High 75–90 · Extreme ≥90. Pressure set = PI ≥ 75; 65 and 85 tested.

From balls to ratings

  • Expectation models (cross-fitted gradient boosting) give what an average player would produce on each ball: same competition, season, over, wickets, batting position, pace/spin, opposition and pressure.
  • Value per ball: runs above expectation minus the run value of a wicket × (out − P(out)). Bowlers get the mirror: runs saved plus credited wickets above expectation. Byes and leg-byes are excluded and run-outs are never credited.
  • Hierarchical shrinkage toward each player's own normal baseline: θ = r·pressure + (1−r)·(a + b·normal), r = n/(n+k).
  • Composite of value, efficiency, dismissal/dot/boundary components, pressure-vs-normal delta and a 10th-percentile lower bound (plus death-over value for bowlers). IPL:T20I blended 70:30. Final score = mean of 18 specifications.
  • Confidence: 300 match-level bootstrap resamples plus robustness across specifications and sample size → High / Medium / Low.
